# Jeu de Morpion en C

Ce projet est une implementation du jeu de morpion (tic-tac-toe) en C. Il permet à deux joueurs de s'affronter sur une grille 3x3 dans un terminal.

## Fonctionnalités

- Fait pour jouer à deux.
- Vérification automatique des victoires et des égalités et gestion des erreurs de saisie des joueurs.
- Affichage dynamique du tableau après chaque tour.
- Interface intuitif.

## Prérequis

Le jeu étant fait en C, vous avez besoin d'un compilateur C (`gcc`, `clang`) ainsi que d'un terminal pour jouer.

## Installation

1. Clonez le dépôt :
